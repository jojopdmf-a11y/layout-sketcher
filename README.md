# Layout Sketcher

A simple drag-and-drop tool for sketching web page layouts in your browser. Add boxes, text, buttons and images, snap them to a grid, then export a PNG.

**Try it live:** https://layout-sketcher.vercel.app

## Make your own version

No build step and nothing to install. The whole app is one file, `index.html`.

1. Download this repo (green **Code** button → **Download ZIP**), or clone it, or click **Fork**.
2. Open `index.html` in any web browser.
3. Edit `index.html` however you like and refresh the page.

Your work saves in your own browser only.

The **Examples** menu includes sample layouts for the [MemoryMap](https://memorymap.world) home page and the [PlayerTracer](https://playertracer.app) website.
